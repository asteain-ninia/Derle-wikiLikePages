いまの公開の手順

  • 1. 保管庫で書く。 出したい記事には frontmatter に 公開: true を書く。手元で確かめるなら、このリポジトリで npm run dev。
  • 2. 保管庫でコミットして push する。 文言がそのまま記事の更新履歴 (編集要約) になる。
  • 3. 待つ。 push をきっかけに Actions が動き、1 分ほどで公開される。手で動かすなら gh workflow run deploy-pages.yml -R asteain-ninia/Derle-wikiLikePages。

決まり

  • 記事をコミットする場所は保管庫だけ。 このリポジトリの content/ は生成物で、git に入れない。
  • 履歴に載せたくないコミットは chore: で始める。 接頭辞なしのコミットは、その記事の更新履歴に載り、その時点の版のページができる。
  • 公開するのは 公開: true がある記事と、それらが名前を書いている画像だけ。 frontmatter が読めない記事は出さない。
  • 2 台の PC で同時に保管庫の git を使わない。 .git も OneDrive で同期されているため。
